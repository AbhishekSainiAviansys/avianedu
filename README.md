## About

**AvianEdu** is the education venture of **Aviansys Technologies** — the aerospace, IoT and
software engineering company ([aviansys-tech.com](https://www.aviansys-tech.com/)). We take the
precision culture of avionics into classrooms and create:

- 📘 **Study material** — modules, worksheets, revision notes &amp; lab manuals (classes 1–12 and entrance)
- 📝 **Mock papers &amp; test series** — chapter tests, pre-boards, full-length mocks with solutions
- 🎒 **Student accessories** — exam kits, geometry sets, branded stationery &amp; event kits

…supplied to **educational institutions**, **online educators** and **competition-conduct agencies**.

This repository is the public **marketing/landing website** for AvianEdu (not the LMS product itself).

## Highlights

- **11 pages + custom 404**, shared sticky header &amp; rich footer (Blade partials)
- ⭐ **Single-file colour theme** — four palettes (*blue* default · *pink* · *dark* · *light*)
  managed entirely from `public/css/theme.css`, with an instant header switcher
  persisted in `localStorage`
- Subtle animations — scroll reveals, count-up stats, subject marquee, floating hero cards,
  testimonial slider, FAQ accordions — all disabled automatically under `prefers-reduced-motion`
- Fully responsive (hamburger menu, adaptive grids) and accessible (ARIA labels, focus rings)
- CSRF-protected contact form with server-side validation
- **No build toolchain** — plain CSS + vanilla JS served straight from `public/` (no npm/Vite needed)

## Quick start

```powershell
# from the project root
composer install
composer env:dev                # copies .env.development and generates a fresh local APP_KEY
php artisan migrate             # builds database/database.sqlite (dev sessions/cache)
php artisan serve               # → http://localhost:8000
```

## Environment configuration (development &amp; production)

Two ready-made environment templates ship with the project:

| File                 | Purpose         | Key settings                                                                 |
|----------------------|-----------------|------------------------------------------------------------------------------|
| `.env.development`   | Local work      | `APP_ENV=local`, `APP_DEBUG=true`, `APP_URL=http://localhost:8000`, debug logs, DB-backed sessions; a fresh `APP_KEY` is generated by `composer env:dev` |
| `.env.production`    | Live servers    | `APP_ENV=production`, **`APP_DEBUG=false`**, `APP_URL=https://your-domain.com`, `LOG_LEVEL=warning` (daily logs), **file-based sessions &amp; cache** (no DB required), `QUEUE_CONNECTION=sync` |

Switch between them with the bundled composer scripts (copies the template to `.env`,
generates a fresh development key, then clears the config cache):

```powershell
composer env:dev    # activate the DEVELOPMENT environment
composer env:prod    # activate the PRODUCTION environment
php artisan env      # verify → "Local" or "Production"
```

> `.env` itself stays git-ignored. The development template contains no key; `composer env:dev`
> generates one locally. Production secrets and keys must be configured separately on each server.

### First-deploy checklist

1. `composer env:prod`
2. Set the real domain: `APP_URL=https://your-domain.com`
3. `php artisan key:generate --force`  ← **use a fresh key on every server**
4. `php artisan config:cache && php artisan view:cache && php artisan route:cache`
5. Point the web-server document root at **`public/`** (never the project root)
6. Confirm `APP_DEBUG=false` — stack traces must never be public
7. (Optional) switch `SESSION_DRIVER` / `CACHE_STORE` back to `database` if you run a DB,
   and configure real `MAIL_*` SMTP values for outbound email

## ⭐ Changing the colour theme (one file)

All four palettes live in **`public/css/theme.css`** — the only file you ever need to edit:

```css
:root,
[data-theme="blue"] {   /* DEFAULT */
    --primary: #0a9bd8;     /* brand blue — matches the logo */
    --primary-dark: #0779ac;
    --heading: #0e2a3d;
    --bg: #ffffff;
    ...
}
[data-theme="pink"]  { ... }
[data-theme="dark"]  { ... }
[data-theme="light"] { ... }
```

- Edit any variable and refresh — every component updates (buttons, cards, footer, gradients…).
- The header swatch switcher sets `data-theme="<name>"` on `<html>` and remembers the
  choice in `localStorage` (`avianedu-theme`); a tiny inline `<head>` script applies it
  before first paint (no flash).
- Blue is bound to `:root`, so the site renders perfectly even with JavaScript disabled.
- `public/css/style.css` contains layout only — **no theme colours are hardcoded there**.
